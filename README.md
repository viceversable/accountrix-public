# Accountrix — Public Brand Assets

Repositorio público con los assets de marca de Accountrix servidos vía **GitHub Pages**.

**Base URL:** https://viceversable.github.io/accountrix-public/

## Estructura

```
/assets/
├── logo/          # Logos Accountrix (PNG, SVG, variantes)
├── socios/        # Fotos de los socios para firmas de correo
├── social/        # Iconos de redes sociales (LinkedIn, IG, WhatsApp, web)
└── firma/         # Assets específicos de firma (banners, separadores)
```

## Uso

Las imágenes se referencian con su URL directa:

```
https://viceversable.github.io/accountrix-public/assets/logo/accountrix.png
https://viceversable.github.io/accountrix-public/assets/socios/david-bencardino.jpg
```

## Por qué este repo existe

Las firmas de correo hechas en Google Docs se rompen porque las imágenes quedan hosteadas en URLs temporales del CDN de Google que expiran. Este repo sirve los assets de forma permanente y pública para que las firmas HTML nunca más se rompan.

## Mantenimiento

Mantenido por Viceversable. Para reemplazar una imagen, subir el archivo con el mismo nombre — se actualiza automáticamente en todas las firmas enviadas.
